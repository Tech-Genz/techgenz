## 🚀 Key Software Projects

### 1. [SharePinz](https://sharepinz.site/) — PIN-Based Ephemeral File Sharing
- **Live Platform:** [https://sharepinz.site/](https://sharepinz.site/)
- **Repository:** [https://github.com/Tech-Genz/SharePinz](https://github.com/Tech-Genz/SharePinz)
- **Description:** An ephemeral file-transfer platform designed for frictionless sharing. Users upload files to encrypted cloud storage, receive a temporary 6-digit numeric access PIN, and share it with recipients for instant download without mandatory account creation or email signups.
- **Tech Stack:** React, TypeScript, Node.js, Express, Cloud Storage, REST APIs, Tailwind CSS.
- **Key Capabilities:** Instant PIN generation, automated Time-to-Live (TTL) storage cleanup, AES-256 cloud encryption, multipart streaming.

### 2. [Tech Genz Digital Experience](https://techgenz.site/) — Interactive 3D Portfolio Platform
- **Live Website:** [https://techgenz.site/](https://techgenz.site/)
- **Repository:** [https://github.com/Tech-Genz/techgenz](https://github.com/Tech-Genz/techgenz)
- **Description:** The flagship website and creative engineering showcase for Tech Genz. Features custom GPU particle physics, interactive Three.js 3D human head geometry with audio feedback, metallic typography, and a modern component architecture built with Vite and React 19.
- **Tech Stack:** React 19, TypeScript, Three.js, WebGL, Tailwind CSS, Vite, GitHub Pages.

## 💻 Local Development Setup

To run the Tech Genz portfolio website locally:

```bash
# Clone the repository
git clone https://github.com/Tech-Genz/techgenz.git
cd techgenz

# Install dependencies
npm install

# Start local development server
npm run dev

# Build production distribution
npm run build

# Preview production build locally
npm run preview
```
